# Проект "Находка"

## Описание

"Находка" — это бесплатный веб-сервис с простыми, полезными и понятными инструментами для каждого.

Главная цель проекта — помогать людям решать повседневные задачи быстро, удобно и без регистрации.

Проект будет развиваться постепенно. Новые функции будут добавляться на основе пожеланий пользователей.

---

# Основные принципы

## Простота

Любой человек должен понять, как пользоваться сервисом без инструкции.

---

## Бесплатность

Основные возможности проекта всегда остаются бесплатными.

---

## Удобство

Если действие можно выполнить проще, выбирается более простой вариант.

---

## Честность

Никаких скрытых функций, рекламы, навязчивых окон и принудительной регистрации.

---

## Развитие

Проект постоянно развивается.

Новые возможности появляются постепенно.

---

## Пользователь

Каждая новая функция должна отвечать на вопрос:

"Действительно ли она будет полезна людям?"

Если ответ "нет", функция не добавляется.

---

# Правила разработки

- Весь код пишется на английском языке.
- Русский язык используется только в интерфейсе.
- Все переменные и функции используют стиль camelCase.
- Код должен быть аккуратным и понятным.
- Каждый файл имеет понятную структуру.
- Все сложные участки подробно комментируются.
- Не использовать сложные решения, если существует простое.
- Безопасность важнее скорости разработки.

---

# Девиз проекта

Просто. Полезно. Бесплатно.
